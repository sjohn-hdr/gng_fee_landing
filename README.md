# HDR Internal Applications

A static React portal linking HDR employees to the GNG and FEE applications.

## Run locally

Install dependencies with `npm install`, then start the development server with `npm run dev`. Open the local URL printed in the terminal, usually `http://localhost:5173`.

To create a production build, run `npm run build`. The static files are written to `dist/`.

## Application URLs

Replace the reserved placeholder URLs in `src/config/applications.ts` with the confirmed GNG and FEE addresses. No other source changes are needed to update the links.
